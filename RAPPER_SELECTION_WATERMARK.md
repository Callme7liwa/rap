## 🎤 Rapper Selection Feature

### What It Does:

- **Select a rapper** from a dropdown list

- **Navigate through** photos with Next/Previous buttons
- **Saves time** - no need to search for images manually

### Where to Find It:

**Location**: Image Tab → "Quick Select Rapper"

```
┌─────────────────────────────────┐
│ Quick Select Rapper             │
│ [Choose a rapper... ▼]          │
│ 3 photos available for 7ARI     │
├─────────────────────────────────┤
│ [← Previous] 1/3 [Next →]       │
└─────────────────────────────────┘
```

### How It Works:

1. Go to **Image** tab
2. Find **"Quick Select Rapper (Auto-load photos)"**
3. Click the dropdown
4. Select a rapper from the list
5. **Photos load automatically!**
6. Use **Next/Previous** buttons to cycle through photos

## ⏭️ Photo Navigation

### Navigation Buttons:

When you select a rapper with multiple photos, navigation buttons appear:

```

│ [← Previous Photo]  2/5  [Next Photo →] │
```

**Features:**
- **Previous Photo** button (← arrow)
- **Photo counter** (e.g., "2 / 5")

The system automatically loads photos from:

1. **Artist Profile Photo** (primary image)

## ⚙️ Technical Details

### How Rapper Photos Are Loaded:

```typescript
1. User selects rapper from dropdown
2. System searches seed.json:
   - Artists array (profile + header)
   - Albums array (cover art)
   - Songs array (song artwork)
3. Collects all unique image URLs
4. Removes duplicates
5. Sets first photo as background
6. Enables navigation buttons
7. Counter shows: current/total
```

### Photo Navigation Logic:

```typescript
Next Photo:
- currentIndex + 1
- If at end → loops to index 0

Previous Photo:
- currentIndex - 1
- If at start → loops to last index

Updates:
- Background image changes
- Counter updates (e.g., "3/5")
- Preview refreshes instantly
```

### Watermark Implementation:

```typescript
Input Features:
- maxLength: 20 characters
- onChange: Auto-converts to uppercase
- Displays in two locations:
  1. Genius Box footer (right side)
  2. Regular templates (bottom-right corner)

Styling:
- Font: Bold, uppercase
- Spacing: Wide letter-spacing
- Opacity: 50-90% depending on template
- Size: 10px (footer) or 12px (corner)
```
